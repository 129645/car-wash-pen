# 運筆練習：開車去洗車 🚗🫧

把觸控筆放在車頭前面的圓圈，沿著車道中線畫到右邊的洗車機，車子會跟在筆尖後面開過去（不會擋住前方的車道）。筆跡會留在畫面上，系統自動統計「超出車道」的次數。

## 玩法
1. 首頁輸入玩家名字（可不填），選一台車（消防車／吊車／警車），選擇從第幾關開始。
2. 用觸控筆按住車頭前面的橘色虛線圈，沿著車道中線慢慢畫到洗車機。
3. 筆離開螢幕時車子會停下，再從車頭前面的圓圈繼續畫即可。
4. 車子開進洗車機就完成一條車道，接著進行下一條。

## 關卡設計
- 共 5 關，難度是車道寬度：第 1 關最寬 → 第 5 關最窄（130 / 105 / 85 / 65 / 48）。
- 每一關都有 5 條車道：直線 → 波浪 → 鋸齒 → 方形彎道 → 半圓彎道。

## 計分方式
- 筆尖從車道內畫到車道外，算超出車道 1 次；回到車道再出去，再加 1 次。
- 筆跡顏色：藍色是在車道內，紅色是超出車道。
- 不能直接跨到隔壁車道抄捷徑，必須順著車道開到底才能進洗車機。
- 每條車道結束顯示超出次數與時間；每關結束顯示 5 條車道的總表。
- 「成果紀錄」可下載 CSV（Excel 可直接開啟）。紀錄只保存在這次開啟的網頁裡，關閉前請先下載。

## 裝置建議
- 平板＋觸控筆最佳。偵測到觸控筆後會自動忽略手掌觸碰。
- 也可用滑鼠或手指操作。

## 檔案
```
index.html          遊戲主程式（單一檔案）
assets/             車子、洗車機圖片與音效
```

## 上傳 GitHub Pages
1. 建立新的 repository（例如 `car-wash-pen`），把這個資料夾內所有檔案上傳到根目錄。
2. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 約 1 分鐘後即可用 `https://<你的帳號>.github.io/car-wash-pen/` 開啟。
